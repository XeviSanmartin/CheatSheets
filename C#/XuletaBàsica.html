4. Math i Aleatoris

Aleatoris:

Random rnd = new Random(); // Declarar 1 cop
int dau = rnd.Next(1, 7);  // Entre 1 i 6

Funcions Habituals:

  • Math.Abs(x): Valor absolut.
  • Math.Pow(b, e): Potència.
  • Math.Sqrt(x): Arrel quadrada.
  • Math.Round(x, 2): Arrodonir decimals.

Exemple: Distància entre 2 punts

Formula: dist = ArrelQuadrada((x2-x1)^2 + (y2-y1)^2)

double dx = x2 - x1;
double dy = y2 - y1;
double dist = Math.Sqrt(Math.Pow(dx, 2) 
                       + Math.Pow(dy, 2));

6. Funcions (Mètodes)

Permeten reutilitzar codi i separar lògica.

// 1. DEFINICIÓ (Fora del Main)
public static double CalculaArea(double radi) 
{
    return Math.PI * Math.Pow(radi, 2);
}

// 2. CRIDA (Dins del Main)
double area = CalculaArea(5.5);
